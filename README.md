# tuantuan — KET for Schools 备考仓库

孩子（北京·海淀·小学二年级）的 **KET for Schools** 备考资料与工具集。
目标：**2027 年 12 月考试达成「卓越 Grade A」**（剑桥量表 140+）。

## 内容

- `KET学习计划.md` — 14 个月分阶段计划（P0 摸底 → P1 积累 → P2 强化 → P3 冲刺）。
- `KET备考工具包.md` — 摸底流程、词汇本/每周打卡表/错题本模板。
- `KET词汇补遗（紧凑版）.docx` — 对照剑桥官方词汇表差缺补漏的精选补遗（11 主题 · 256 词目，版式对标原表）。
- `超纲筛查报告.txt` — 对用户提供的两份 AI 词表做的官方边界核对结论（0 个真正超纲词）。
- `KET材料/` — 从剑桥官网下载的官方样题（阅读/听力/口语/答案/原文）与词汇表、考生须知、分数换算指南。
- `*.py` / `*.txt` — 词表抽取、差集、音标构建、超纲筛查等工具脚本与中间产物。

## 约定

- 本仓库**仅**用于本项目内容。
- 推送走 `gh_push.py`（GitHub REST API，因本机 git:443 被墙）；仓库指向见根目录 `.ghrepo`。
- 大文件（>5MB，如样题 MP3 / zip）受脚本限制未入库。
