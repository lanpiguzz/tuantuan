# tuantuan — 团团的学习任务仓库

孩子（团团）的**多任务学习资料与工具集**。按任务（科目 / 项目）分目录存放，每个任务一个顶层文件夹，互不影响。

## 目录结构

```
tuantuan/
├── README.md          # 本文件：仓库总览
├── .gitignore         # 排除 .workbuddy 等内部目录
├── .ghrepo            # 仓库指针 = lanpiguzz/tuantuan
├── ket/               # 任务一：KET for Schools 备考（英语）
│   ├── KET学习计划.md
│   ├── KET备考工具包.md
│   ├── KET词汇补遗（紧凑版）.docx
│   ├── 超纲筛查报告.txt
│   ├── KET材料/        # 剑桥官方样题 / 词汇表 / 考生须知
│   └── *.py / *.txt    # 词表抽取、差集、音标构建、超纲筛查等工具脚本
└── （未来任务）         # 如 math/、science/ …… 各自开一个顶层目录
```

## 现有任务

目标：**2027 年 12 月考试达成「卓越 Grade A」**（剑桥量表 140+）。
- 14 个月分阶段计划（P0 摸底 → P1 积累 → P2 强化 → P3 冲刺）。
- 对照剑桥官方词汇表的差缺补漏补遗（11 主题 · 256 词目，版式对标原表）。
- 超纲筛查结论：用户提供的两份 AI 词表 0 个真正超纲词。
- 剑桥官方样题（阅读/听力/口语/答案/原文）与词汇表、考生须知、分数换算指南。

## 约定

- 仓库按**任务分目录**：每个任务一个顶层文件夹；新增任务直接在根目录新建对应文件夹。
- 推送走 `gh_push.py`（GitHub REST API，因本机 git:443 被墙）；仓库指向见根目录 `.ghrepo`。
- 大文件（>5MB，如样题 MP3 / zip）受脚本限制未入库，官方样题均可官网再下载。
- 仅收录团团的学习任务内容；其他项目（go2rich / learning / KVC 调研等）不在此仓库。
