# KET 官方样题与备考资料 · 使用说明

> 本文件夹为剑桥官方免费提供的 A2 Key for Schools 样题与备考资料，用于 P0 摸底与日常参考。
> 配套计划见根目录 `KET学习计划.md` 与 `KET备考工具包.md`。

## 一、样题包（摸底核心，已解压在 `KET材料/样题/`）

| 文件 | 是什么 | 摸底时怎么用 |
|---|---|---|
| A2 Key for Schools 2022 sample Reading and Writing - questions v2.pdf | 阅读与写作卷（真题样题） | 让孩子做：阅读 5 部分 30 题 + 写作 2 篇 |
| A2 Key for Schools 2022 sample Reading and Writing - answer key.pdf | 阅读写作答案 | 对答案，记对题数（阅读目标≥28/30 冲卓越） |
| A2 Key for Schools 2022 sample tests Listening - question paper.pdf | 听力卷 | 配合 MP3 做，每段放两遍 |
| A2 Key for Schools 2022 sample tests Listening - answer key.pdf | 听力答案 | 对答案（目标≥23/25） |
| A2 Key for Schools 2022 sample tests Listening - tape script.pdf | 听力原文 | 错题回听、跟读对照 |
| a2-key-for-schools-listening-sample-test.mp3 | 听力音频 | 模考/练习时播放 |
| A2 Key for Schools 2022 sample tests Speaking.pdf | 口语卷（考官/考生框架+图片） | 家长照 Part1 问答 / Part2 看图说，观察敢不敢开口 |
| Test & Train information for students / teachers.pdf | 官方在线练习平台说明 | 可选，了解数字化练习资源 |

## 二、备考资料（已下载在 `KET材料/备考资料/`）

- **a2-key-2020-vocabulary-list.pdf** — 官方词汇表（按话题分类）→ 直接按它给词汇本建词卡
- **a2-key-for-schools-information-for-candidates.pdf** — 考生须知（考试流程 / 题型 / 计分说明）→ 摸底前先读懂
- **converting-practice-test-scores.pdf** — 模考分数 → 剑桥量表换算指南 → 冲刺期用来估分定级

## 三、P0 摸底操作顺序（不计时、不施压）

1. 先读 `information for candidates` 了解题型与流程，翻一遍 `vocabulary list` 看词汇范围。
2. 做 **阅读写作卷** + **听力卷**（MP3 放两遍），填工具包里的《三项能力观察记录表》。
3. 用 **口语卷** 做 Part1 / Part2 陪练，记录「敢开口 / 犹豫 / 需提示」。
4. 对照 answer key 计对题数，结合工具包 Step4 定级（Think 从 Starter 还是 Level 1 起）。
5. 用官方词汇表按话题建词汇本，开始 P1。
